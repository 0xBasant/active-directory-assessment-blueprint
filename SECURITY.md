# Security Policy

Do not open a public issue containing customer data, credentials, hashes, tickets, private keys, tokens, assessment evidence, or a live exploitation path.

If a contribution accidentally contains sensitive material:

1. stop sharing or cloning it;
2. notify the repository owner through a private channel;
3. rotate/revoke affected credentials or artifacts immediately;
4. treat deletion from the latest commit as insufficient—coordinate history removal and downstream cleanup;
5. preserve only the minimum incident evidence required.

This repository is documentation and safe planning code. A report that the repository does not include executable offensive tooling is not a security vulnerability.
